# Corrected backend baseline — v0.2

This revision is a corrective pass over the first backend ZIP. It keeps the modular-monolith architecture while fixing correctness, persistence, packaging, import and operational issues found during review.

## Main corrections

- Corrected canonical catalogue typing (`classifications` and `source_references` are arrays, not objects).
- Kept `GenericSolutionSlot` as a first-class relational child while preserving product-specific properties/metrics in JSONB.
- Restored the full backend specification and documented the later Slot/import amendments.
- Fixed Python package discovery so all `app.*` subpackages are included in the wheel.
- Added a migration that professionalizes Manufacturer, User, CommercialSolution and Asset persistence without losing the v1.0 upgrade path.
- Replaced direct asset-owner columns with `generic_solution_assets` and `commercial_solution_assets` association tables.
- Added CommercialSolution workflow audit fields and `technical_data` JSONB.
- Made IFC validation depend on actual IfcOpenShell parsing; no string-based fallback is accepted.
- Added staged filesystem writes and rollback cleanup for uploads/imports.
- Added safe asset detachment/deletion so shared Asset rows/files are not removed while still linked elsewhere.
- Hardened production configuration, authentication edge cases, UUID parsing and HTTP error normalization.
- Improved Docker packaging, non-root execution and `.dockerignore` hygiene.
- Expanded OpenAPI and README documentation.

## JSON + IFC administrative imports

Source workspaces:

```text
data/import/generic_solutions/
data/import/manufacturer_solutions/
```

Machine schemas:

```text
schemas/import/generic_solutions.schema.json
schemas/import/manufacturer_solutions.schema.json
```

Examples:

```text
data/examples/generic_solutions.example.json
data/examples/manufacturer_solutions.example.json
```

Import commands:

```bash
python scripts/import_data.py generic data/import/generic_solutions --validate-only
python scripts/import_data.py generic data/import/generic_solutions

python scripts/import_data.py manufacturer data/import/manufacturer_solutions --validate-only
python scripts/import_data.py manufacturer data/import/manufacturer_solutions
```

Manufacturer imports only create/update `DRAFT` CommercialSolutions and cannot bypass submission or administrator approval.

- SQLAlchemy mapper configuration and PostgreSQL DDL compilation.
